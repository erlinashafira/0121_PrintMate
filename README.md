# PrintMate

> **Aplikasi Manajemen Pesanan Percetakan Merchandise**

PrintMate membantu vendor percetakan merchandise (misalnya stiker, pin, gantungan, dan art print) mencatat pesanan pelanggan secara digital. Aplikasi dibangun dengan **Kotlin Jetpack Compose** dan terhubung ke **REST API** dengan database **MySQL**
